The insight03

A reference key turns a payment
into a receipt the server can verify.

Each invoice carries a fresh public key. The payer includes it in the transaction. The gateway looks the payment up by reference instead of trusting the caller.

Verification05

The server checks the chain,
not the caller.

  • 01Look up by reference. Find every transaction that mentions the invoice key.
  • 02Measure the merchant delta. Balances after minus balances before, filtered by owner and mint.
  • 03Burn the reference. One reference buys exactly one response, so replay is impossible.

Paying in the wrong mint is rejected, not credited. Underpaying by one base unit is rejected.
